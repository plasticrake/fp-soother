# fp-soother

A Python BLE library for the **Fisher-Price Smart Connect Deluxe Soother** (model DYW47).

The official app was discontinued in 2024, leaving many users with a device that could no longer be fully controlled. This library gives you direct BLE control from Python.

## Packages

- [fp-soother-lib](packages/fp-soother-lib) — Core Python BLE library for the Fisher-Price Smart Connect Deluxe Soother.
- [fp-soother-cli](packages/fp-soother-cli) — Command-line interface for controlling the soother.
- [fp-soother-web](packages/fp-soother-web) — Local web UI for controlling the soother.
- [fp-soother-util](packages/fp-soother-util) — Shared utilities for fp-soother packages
